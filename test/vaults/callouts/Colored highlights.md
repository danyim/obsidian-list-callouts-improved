# Colored highlights

Highlights in one of Obsidian's colors (1.14 and later), written with the
color's emoji after the opening `==`. Each callout is a color other than the
highlight's, so which of the two is painted can be told apart.

==🔴@ Red note== text

==🟦$ Blue success== text

A plain ==🔴red highlight== with no character.

==🟢~ Green idea that runs
onto the next line== text
