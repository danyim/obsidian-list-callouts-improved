# Highlights

One inline highlight per built-in callout character, plus highlights that must
*not* become callouts.

==& Important== text

==? Question== text

==! Warning== text

==~ Idea== text

==@ Note== text

==$ Success== text

==% Muted== text

Two on one line: ==& first== and ==! second==.

A plain ==highlight== with no character.

Only a callout when the space is optional: ==!important==

Inline code is left alone: `==& code==`

```md
==& fenced==
```

- & List callout with ==! inline== highlight
